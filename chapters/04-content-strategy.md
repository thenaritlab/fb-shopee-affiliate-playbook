## Core Framework

``` text
HOOK → PROBLEM → SOLUTION → BENEFIT → CTA
```

### Content Mix

-   70% Value
-   20% Review / Explanation
-   10% Promotion

### 10 Angles

Problem/Solution, Benefits, How-to, FAQ, Mistakes, Who is it for, Who
should skip, Comparison, Use Case, Campaign

### Repurpose

``` text
1 Product Brief
├─ 5 Hooks
├─ 3 Posts
├─ 1 Carousel
├─ 3 Reel Scripts
└─ 5 CTA Tests
```

### Rule

สร้าง Hook หลายตัวก่อนลงทุนผลิต Video
