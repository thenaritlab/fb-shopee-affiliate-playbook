# Facebook × Shopee Affiliate Playbook

![FB Shopee Affiliate Playbook](assets/affiliate-playbook-logo.png)

**Professional Step-by-Step Playbook: Beginner → Intermediate →
Advanced**

สร้างระบบ Facebook × Shopee Affiliate ตั้งแต่ **หาไอเดีย → เลือกสินค้า → สร้าง
Content → AI Video → Publish → Analytics → Optimization → Scale**

> **เป้าหมายตัวอย่าง:** พัฒนาระบบให้มีโอกาสสร้าง Commission เฉลี่ย ฿500/วัน\
> เป้าหมายนี้ใช้สำหรับวาง Business Funnel และไม่ใช่การรับประกันรายได้

## 🐙 GitHub Update Commands

ถ้า Repository มีอยู่แล้ว ให้ Copy V4 ทับไฟล์เดิมแล้วใช้:

``` bash
cd C:\dev\fb-shopee-affiliate-playbook

git status
git add -A
git commit -m "Add README table of contents and quick navigation"
git push origin main
```

หลัง Push ให้เปิด README แล้วทดสอบลิงก์ **Chapter 00, 05, 10 และ 14**
